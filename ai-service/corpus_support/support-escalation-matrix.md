# Support Escalation Matrix (internal)

> SAMPLE internal document for the POC. Staff only. Not an official DSports procedure and it contains no SLA.

| Situation | Escalation requested by the assistant |
|---|---|
| Order marked delivered, customer did not receive it | Yes: delivery proof is not available to the assistant |
| More than one successful payment for one order | Yes: confirmed discrepancy, financial |
| Successful payment on an order that is not confirmed | Yes: records disagree |
| Return approved, no refund recorded | Yes: a person must start the refund |
| Refund amount lower than the amount paid | Yes: the customer disputes the difference |
| Return rejected and the customer disputes it | Yes: only a person can review a decision |
| Safety concern reported | Always |
| Delayed shipment past its estimate or stalled | No: a case is proposed |

An escalation REQUEST is not an assignment. It becomes ACCEPTED only when a support executive takes the case.
