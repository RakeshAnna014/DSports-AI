# Exchange Policy

> SAMPLE DSports document, written for the demo knowledge base. It is a reference/demo policy, not an official DSports policy.

## Is there an exchange?

DSports does not have an exchange function. You cannot swap a product for another size, colour or model in one step.

## What you can do instead

If the product is eligible for return (see the Return Policy: a delivered order, inside the 7-day return window), you can
return it and place a new order for the size or model you want. The return eligibility check shows the exact deadline.

If the product is not eligible for return, or you would like a person to consider an exchange, raise a support case and say
what you need. A support executive decides; the assistant cannot promise an exchange.

## Ordering the wrong size

A wrong size that you chose when ordering is handled the same way. DSports does not treat it as a delivery error, and the
assistant will not describe it as one.
